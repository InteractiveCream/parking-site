# Smart Parking Tracker - Lite 🚗

מערכת חניון חכם המציגה לשומר את הרכבים הנכנסים בזמן אמת, מבוססת על ארכיטקטורת Microservices ב-Docker.

## תכונות המערכת
* **שרת Web (Nginx):** מריץ את ממשק המשתמש של השומר בפורט 80.
* **שרת Storage (Apache):** מאחסן את תמונות לוחיות הרישוי בפורט 8080.
* **Data Persistence:** שימוש ב-Volumes כדי לשמור את תמונות הרכבים גם במקרה של נפילת השרתים.
* **תוספת אישית:** הוספתי כפתור "מצב לילה" (Dark Mode) לנוחות השומר במשמרות לילה.

## הוראות הרצה
1. הורידו את הפרויקט.
2. פתחו טרמינל בתיקיית הפרויקט.
3. הריצו: `docker compose up -d`
4. היכנסו בדפדפן לכתובת: `http://localhost`
